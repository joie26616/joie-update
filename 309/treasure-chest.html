还原 · V2 宝箱弹框规则

  • 触发:在首页 / 我的完成任务时自动弹出全屏宝箱弹框(非列表);文案「恭喜您完成 X 奖励任务 / 开启宝箱可获得 A~B 的彩金」(展示区间)。
  • 多任务:同时完成 N 个 → 宝箱弹出 N 次(逐个开,开完一个弹下一个)。
  • 优先级:宝箱与通知同时触发 → 优先宝箱弹框,通知排队等宝箱关闭后再弹。
  • 开箱:点「开启宝箱」→ 抖动→弹开→金币迸出 → 揭晓实际随机金额(真实区间 ActualReward 内随机,非展示区间)→ 统一成功弹窗显实际额。

309 优化(在 V2 规则上叠加)

  • 领取形式(#4):开宝箱 = ReceiveType=2;后端从 ActualReward 随机,DisplayReward 仅用于「可获得 A~B」文案。
  • 领取方式(#4):即时类宝箱→完成即弹开;任务结束类宝箱→任务结束后才可开,领取有效期内每天登录仅自动弹一次(弹框显实时倒计时:剩 N 天 HH:MM:SS),也可随时在领奖中心(bonus collection)开箱;过期回收、不再弹。
  • 统一去重:开箱发奖幂等,与统一领取状态机一致;漏开的任务结束类宝箱可在 bonus collection 待开。
