🟣 更新点(#1 展示条件 + #4 领取方式)

#1 展示条件:每个任务新增「展示条件」= 默认「全员」可见,或选「充值要求」→ 填 [首充/人] 金额,首充达标会员才展示。
#4 领取方式:V1 领取方式(直接领取 / 开宝箱领取)不变,新增「任务结束」;选中出 2 个选项:① 直接领取 ② 宝箱领取;并可设「领取有效时间(天,默认 0=不限期,以任务结束时间为准)」。
[目标] 列说明(309 优化展示,不照抄 V1):V1 现状该列仅显示纯数字 TaskTarget(充值投注任务显示「充值目标,投注目标」两数,如 1000,5000);本页按 309 优化保留描述性文案(如「充值 ≥ 100」「有效邀请 ≥ 1 · 首充 ≥500/人」),其中「首充 ≥N/人」为 🆕#38 新增门槛、非 V1 字段 —— 开发落地时 [目标] 列仍存纯数字 TaskTarget,#38 首充门槛为独立新增字段(仅任务分类=邀请人时生效),列表展示文案由前端拼接,不改 V1 数据结构。

⚠️ 数据逻辑问题

1. 次日快照丢字段(关键)—— V1 任务走「配置表 → 次日快照(Detail)」复制;新增字段若没同步进快照复制逻辑,次日快照将缺「展示条件 / 领取方式 / 领取形式 / 有效时间」,导致次日展示判定与领取校验失效。
2. 存量突变 —— 存量任务无新字段,若默认值处理不当会改变原有行为(如原本全员可见变成不可见)。

✅ 解决方案

1. 同步扩展次日快照表字段 + 复制逻辑,保证 Config→Detail 携带全部新字段。
2. 新字段给默认值 = 旧行为(展示条件=全员 / 领取方式=V1 现状(直接/开宝箱) / 有效时间=0 不限期),兼容存量。
3. 领取校验:「任务结束领取」需到期且在有效期内;领取走统一状态机 + 幂等去重。
